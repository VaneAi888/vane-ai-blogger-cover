# 本次封面简报

`new-job` 接收字段示例，替换所有本次具体值；库的修订由脚本读取并写入，不能手工虚构。

```json
{
  "title": "本次准确标题",
  "theme": "本次主题及视觉表达",
  "platform": "用户选择的平台",
  "mode": "remix",
  "font_direction": "沿用库中的超粗黑体",
  "dimensions": {"3:4": [1080,1440], "16:9": [1920,1080], "4:3": [1600,1200]},
  "extra_materials": [],
  "extra_materials_answer": "用户明确不添加额外素材",
  "style_asset_ids": ["从风格库选定的完整资产ID"],
  "template": "从风格库选择的模板",
  "selection_reason": "结合主题与具体参考编号的选择理由",
  "identity_free": false,
  "identity_free_instruction": "",
  "persistent_preference_exceptions": [],
  "prompt": "实际执行的生成提示词"
}
```

`extra_materials` 填本次素材的可读绝对路径。脚本复制到任务中，避免对话结束后丢失。无人物例外仅在用户明确要求时用 `identity_free: true` 并引用原话；它不会初始化身份库。尺寸必须是正整数且与各自比例匹配；精确像素做不到时保留用户要求与实际文件大小，register-output 会记录差异，不会谎报已达标。

可把长提示词另存任务目录 `prompt-3x4.md`，修订时保存 `prompt-3x4-v2.md`；横版也保存各自提示词。文件里不放会替换身份/风格的隐藏默认值。

## 生成提示词内容

1. 图像角色：身份图用于本人五官，风格图用于构图与排版，额外素材用于准确产品/Logo/背景；解释每张图的角色，不依赖文件名猜测。
2. 画幅和预期像素，所选生成模式和被锁定的部分。
3. 主题的具体场景，人物位置/姿态/比例，产品位置与尺度；可用归一化0–1坐标辅助描述。
4. 主标题逐字内容、分行、层级、字体方向、配色、描边/投影、可读性和安全边距。
5. 风格库中适用的背景、光线、情绪规则及本次用户例外。
6. 不携带参考博主面孔、账号、水印、旧标题、旧版本号；不擅加新文案或Logo。

以上是提示词内容而非固定的工具参数。内置工具能接受路径时传持久原图的绝对路径；使用最近图片时先显示真正的身份/风格参考，取覆盖全部目标图的最少数量，不把上一聊天的图片视作当前可见。

## 横版适配

通过用户确认的主封面进行重排，人物与重要道具沿用视觉识别。

- **16:9**：将竖版上方标题区移到横版一侧，人物和产品置于另一侧；也可沿主封面的结构让标题横跨上部，但不遮脸。扩展背景承接原场景，保留标题与主视觉的对比关系。
- **4:3**：适度减少纵向空白，让标题形成更短的顶部一至两行，人物/产品中心关系不变；必要时将辅助道具移到侧边。
- 不增加卖点、角色或次级标题凑版面，不变更本人五官。约5–8%的关键元素边距是本 Skill 设计建议；用户提供平台遮挡区时按其真实数据执行。每张检查实际比例、文案、脸部及Logo。用户只改横版时保留主封面的确认；用户改主封面时重新确认新版本。
